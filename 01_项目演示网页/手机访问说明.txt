E路退手机访问说明

客户说的“移动端能打开”，如果是指手机输入网址就能用，需要把网页通过服务器发布出来。

本项目是静态网页，已经支持手机屏幕自适应；手机访问有两种方式：

一、同一 WiFi 下临时演示
1. 电脑进入“01_项目演示网页”文件夹。
2. 双击“启动手机访问.bat”。
3. 保持弹出的黑色窗口不要关闭。
4. 手机和电脑连接同一个 WiFi 或同一个热点。
5. 在手机浏览器输入窗口里显示的地址，例如：
   http://10.56.225.229:8010/index.html

如果打不开：
1. 检查手机和电脑是不是同一个网络。
2. Windows 防火墙弹窗时选择允许访问。
3. 如果窗口里有多个 IP 地址，可以每个都试一下。

二、真正给别人远程访问
如果希望客户或老师不在同一个 WiFi 下也能打开，就需要部署到线上，例如：
1. GitHub Pages
2. Netlify
3. Vercel
4. 学校或个人服务器

上线后，对方直接打开公开网址即可使用，不需要运行 Python 服务。

当前项目本身已经是静态网页结构，适合直接部署。
