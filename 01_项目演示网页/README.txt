E路退项目演示网页使用说明

1. 打开方式
进入本文件夹后，双击 index.html 即可打开网页。网页依赖 data 文件夹中的样本数据，请不要把 index.html 单独移走。
如果要让手机输入网址访问，双击“启动手机访问.bat”，手机和电脑连接同一个 WiFi 后，按窗口提示输入 http://电脑IP:8010/index.html。

2. 推荐浏览顺序
经营总览 -> 跨境税费计算器 -> 数据样本 -> 数据看板 -> 风险与机会 -> 商品对比 -> 数据资产 -> AI分析报告。

3. 四组样本含义
样本A 综合均衡：适合看完整流程。
样本B 高利润版：适合看节税和利润提升。
样本C 高风险版：适合看资料缺失、申报不完整等风险提醒。
样本D 平台对比版：适合看不同平台的销售额、利润和节税差异。

4. 上传自己的数据
网页支持上传 CSV / JSON。字段可以参考 data/orders_template.csv。字段越完整，利润、免税条件和风险分析越准确。

5. 报告功能
“下载分析报告”会导出当前筛选条件下的摘要，适合放入课程报告或作为答疑材料。

6. 注意
网页中的税费和利润计算是课程项目中的简化估算，用于理解政策影响和数据分析思路，不作为真实纳税申报依据。
