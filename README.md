# Cross-Border Tax Analytics Platform

A course project demo for cross-border ecommerce order analysis, simplified tax estimation, risk alerts, and report generation.

## Contents

- `01_项目演示网页`: Static web demo with sample datasets and analysis tools
- `02_上台展示PPT`: Presentation files
- `03_说明与讲稿`: Documentation and speaking notes
- `04_素材与截图`: Screenshots and visual assets
- `05_演示备注`: Demo notes

## Web Demo

Open `01_项目演示网页/index.html` in a browser, or run `01_项目演示网页/启动手机访问.bat` for LAN mobile access.

The calculations are simplified for coursework and should not be used for real tax filing.
