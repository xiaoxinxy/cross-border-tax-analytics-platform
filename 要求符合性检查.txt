一、与课程方向的对应关系

1. 项目主题
已符合。项目名称为“E路退”，方向是跨境小包“无票免税”计算/分析工具。

2. 灵感来源
已覆盖。项目围绕跨境电商“无票免税”政策、跨境退税/免税分析和厦门自贸片区中小卖家场景展开。

3. 工具一句话描述
已覆盖。项目定位是：面向跨境电商小包卖家的订单利润、无票免税判断、节税空间和风险分析工具。

4. 为什么适合厦门大学生做
已覆盖。说明材料中已经强调厦门跨境电商、自贸片区、保税区和中小卖家场景，学生可以用样本数据和访谈思路完成课程展示。

5. 核心功能模块
已覆盖：
- 多平台销售数据导入：网页支持内置样本、CSV、JSON 上传。
- 无票免税智能匹配：根据是否有发票、综试区登记、出口申报、货物适用性等字段进行演示判断。
- 利润测算：计算销售额、成本、物流费、平台佣金、推广费、税费和免税前后利润。
- 可视化展示：包含销售走势、类目节税贡献、平台占比、风险分布、商品排名。
- 报告生成：网页可生成通俗版 AI 分析报告，并支持复制/下载。
- 表格化交付：新增表格样式数据包，包含样本分类、经营汇总、平台汇总、类目汇总、商品编码库和订单明细。

6. 技术路径
已补强。当前版本采用 HTML + CSS + JavaScript 做成可直接打开的网页原型，同时补充了题目建议的技术材料：
- data/orders_template.xlsx：Excel 上传模板；
- tools/pandas_cleaner.py：Python Pandas 清洗、匹配和利润测算脚本；
- data/product_code_db.csv：小型商品编码数据库；
- tools/matplotlib_report.py：Matplotlib 图表报告脚本示例；
- tools/streamlit_app.py：Streamlit 快速数据应用原型。
- data/E路退_表格样式数据包.xlsx：带表头样式、筛选、冻结窗格和分类页的 Excel 数据包。

7. 调研与访谈对象建议
已在说明材料中补充。可讲厦门自贸片区跨境电商产业园、跨境电商协会、Amazon/Temu/Shopee/TikTok Shop 小卖家等对象。

8. 可参赛/应用方向
已覆盖。适合课程项目、挑战杯、大创项目、一带一路专项、大学生创新创业展示等。

二、还可以怎么讲得更稳

1. 不要把项目说成正式报税系统。
更稳的说法是：这是课程展示用的数据分析工具，用来解释政策影响、经营利润和合规风险。

2. 不要只讲页面好看。
建议按“订单导入 -> 政策条件判断 -> 利润测算 -> 风险预警 -> 报告输出”的逻辑讲。

3. 样本数据要分类讲。
样本A讲完整流程，样本B讲利润提升，样本C讲风险边界，样本D讲平台差异。

4. 技术实现可以这样说。
前端用 HTML/CSS/JS 完成可交互原型；数据层保留 Excel/CSV/JSON 模板；Pandas 脚本负责数据清洗、商品编码库匹配和利润测算；Matplotlib 脚本可生成报告图表；Streamlit 文件展示后续可快速部署的数据应用版本。

5. PPT 怎么讲。
正式展示版 PPT 已按“核心能力 -> 处理链路 -> 交互看板 -> 样本分类 -> Pandas -> 商品编码库 -> 看板 -> 风控 -> 数据资产 -> 演示路径”重排。每页只讲一个重点，避免把大量文字堆在同一页。
